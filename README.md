# PIzza--sales--Dashboard# 🍕 Pizza Sales Analysis Dashboard

An interactive Power BI dashboard that analyzes pizza sales to uncover ordering patterns and top revenue drivers.

## Key KPIs
- Total Revenue: 329K
- Total Orders: 8,577
- Total Quantity: 20K pizzas
- Average Order Value: 38.40
- Average Pizzas per Order: 2

## Features
- Slicers for pizza category, size, and month
- Daily and monthly order trends
- Revenue breakdown by category and size
- Best/Worst Sales page by pizza name

## Key Insights
- Orders peak on Fridays and Thursdays, and in January and March.
- Classic is the top category (26.37% of revenue).
- Large size contributes the most revenue (46.18%).
